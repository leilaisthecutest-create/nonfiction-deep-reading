# 教学深度与迁移

## 词汇与语言

按主题、复现价值和输出需要分 Core / Supporting / Recognition。通常核心与支持各5–8个，依据文本和水平调整。不是所有红色词都值得同样篇幅。

核心词按实际价值选择：准确音标与词形、原句与语境义、常用词族、自然搭配/结构、近义辨析、2–3个自然新例句（至少一个跨主题）、真实常见错误、从识别到独立表达的练习。不能捏造词族或冷僻错误凑维度。教师版补教学追问、误区与参考答案；学生版提供精选解释与练习。

支持词重点讲语境义、搭配及例句；识别词简释即可。按语义联系组合学习单元，不机械固定词数或每页词数。

选2–4个高价值结构，解释 Form → Meaning → Use → Contrast → Transfer。复杂句沿 Original Sentence → Chunking → Structure → Meaning Reconstruction → New Context Practice 展开。讲清为何使用，而不仅是公式。新例句单独标为语言扩展。

## 精读与提问链

逐段确定主旨、信息组织、关键细节、语言重点、作者选择与思维任务。不同段落有不同重点，不重复一套空泛问题。

每个核心重点设计 Notice → Understand → Analyze → Explain → Apply 的递进问题，给出可说出口的英文问题、合理预期答案、追问、教学意图与典型误解。层次可按文本自然合并，避免五个形式化问题。

Adventure Islands 示例：A建立国家与活动概览；B解释火山活动与目标；C包含仪式背景、动作、参与角色。总述—分述是作者结构；比较是读者整理策略，不能说原文所有段落都是逐点对比。C不是仅有动作的过程段，也不是结论。

## 阅读到输出

Text Input → Noticing → Guided Practice → Output Sentence → Independent Explanation。最终作品需要针对受众重新组织信息，例如展览介绍、科学解释卡、建议说明或证据简报。按文本选择，不强制每篇都当展览编辑。

A2可用拆句、词库、中文教师解释和短输出；B1逐步撤掉句框；B2增加证据限制、观点比较与独立论证。降低语言负担，保留思考挑战。

## 项目

真正项目应有学生角色、受众/使用情境、可展示的作品，以及 Investigate → Research → Design → Test/Evaluate → Revise → Present。测试记录实际读者理解或明确评价数据；不预填伪造结果。数字抄录和简单绘图应称为练习，不标为完整PBL。学科拓展需要可靠外部材料；资料不足时缩小项目范围。涉及冒险的文章可做信息设计，不把活动过程图变成学生模仿操作指南。
